表格内容词汇替换

原功能 → 新位置

  • 表格目录读取状态（读取中 / 读取失败）→ 页面顶部状态行，文案沿用源码。
  • 已生效规则汇总 → 首个分组「已生效规则」：只读已保存配置，仅列已启用且通过校验的规则；「合计」行显示「N条」，每组显示「N 条」；空白值显示「（空白）」，换行 / 制表 / 空格显示为 ↵ ⇥ ·。
  • 全局替换开关 → 「全局替换」分组首行开关，适用范围说明作为副标题；匹配方式与保存提示放在分组页脚。
  • 规则编辑（原词、替换为、↑、↓、删除）→ 每条规则一个块行，操作在标题行右侧；区域末行为「添加规则」「保存并应用」。
  • 单表下拉选择 → 「选择表格」行 + 底部选择表；已配置的表不再列出，不可用表置灰并标「（当前不可用）」，无可选项时显示「没有可添加的表格」。
  • 每张单表配置 → 独立分组：表名作分组标题并带「当前不可用」徽标，组内依次为「启用此表替换」、规则、「移除配置」；不可用时页脚提示规则保留。
  • 保存校验错误 → 显示在对应规则下方，输入框加危险色描边，并以 aria-describedby 关联。
  • 替换为空的保存确认、移除单表确认、结果提示 → 沿用源码标题、正文与按钮文案。

新增 / 改动交互

  • 新增确认：删除单条规则前弹出确认框；删除只改草稿，点「保存并应用」后才写入。
  • 改动：选择表格由原生下拉改为行 + YZ.sheet。
  • 未加入源码不存在的「重置」。
  • 工具栏「模拟目录」在正常 / 读取中 / 读取失败间切换（目录不可用时单表区域按不可用显示，「选择表格」置灰）；「保存结果」切换成功 / 失败。
