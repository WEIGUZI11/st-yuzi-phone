读取世界书

自动排除关键词

条目 comment 包含任一关键词时自动取消勾选；不检查条目正文。每行一个关键词。

条目范围

默认读取当前角色主世界书和附加世界书中的所有未禁用条目。

原功能 → 新位置
1. 标题栏「刷新」#phone-worldbook-reading-refresh → nav 右侧文字按钮（标题栏结构不变）。
2. 「自动排除关键词」textarea（rows=6，placeholder「例如：MVU」）+「保存排除词」→ 同名分组：块行 textarea + 行内动作按钮；原区块描述移到 group-footer。保存时按行拆分、trim、去空、去重后重算勾选，无 toast（与现状一致）。
3. 「条目范围」搜索框（label「搜索条目」）→ 分组标题下方 search-row，label 改为读屏可见文本；按条目名 / 书名 / UID 不区分大小写实时过滤。
4. 「全选 / 取消全选」→ 状态行右侧 mini-btn，只作用于当前搜索结果中的未禁用条目。
5. 状态行「已选择 {selected}/{enabled} 个未禁用条目」→ 与按钮同一行；计数始终按全部条目统计，不受搜索影响。
6. 条目复选框 → shared switch；标题为 comment ?? name，空时「条目 {uid}」；副标题「{书名} · 主世界书/附加世界书」；已禁用条目开关 disabled 且标题置灰。
7. 列表四种状态 → 卡片内 .empty：「正在读取角色世界书...」、错误文本（危险色）、「未找到匹配的条目」、「当前角色没有可读取的世界书条目」。失败仍以内联错误块替换列表，不用 toast。
新增 / 改动建议
· 「已排除」灰标签（改动建议）：现状被关键词排除的条目只显示为未勾选，无任何提示。现状下手动打开其开关会写入偏好，但重载后仍为关闭；原型如实演示这个回弹，并建议正式版直接禁用其开关。
· 「已禁用」灰标签（改动建议）：现状只有 is-disabled 置灰。
· 刷新显示加载（改动建议）：现状刷新调用 load(false)，不重绘加载态，列表只会在结果返回后静默更新；原型点击刷新后显示约 0.8 秒加载态，期间按钮置灰。
· 保存排除词 / 切换条目失败时，现状同样用错误块替换整个列表，直到下一次成功读取，原型「错误」按钮可预览该形态。
· 顶部工具栏「加载中 / 错误 / 空列表 / 恢复数据」仅为原型预览；返回按钮在原型中只弹出预览提示。
· 未展示：catalog 会过滤 QQ 投影条目（YuziQQ｜ 前缀或 yuziPhoneQQV2），以及没有 uid、没有书名的条目，它们不出现在列表里。
