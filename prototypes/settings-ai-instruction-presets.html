AI 指令预设

导入、导出与恢复

导入 JSON 文件。「恢复当前」仅对内置预设可用；「恢复全部」恢复四份内置预设，自定义预设不会删除。

保存

名称不能与已有预设重复；内置预设不可删除。

消息块

消息块按顺序拼成请求，可用上移 / 下移调整顺序。

占位符说明

把占位符写入任意消息块内容，发起请求时会替换为对应资料。

原功能 → 新位置
  • 「选择预设」下拉 → 首组「选择预设」行 + YZ.sheet；内置预设带「内置」角标，新建未保存时列出「新建 AI 指令预设（未保存）」
  • 「新建 AI 指令预设」按钮、「预设名称」输入（最多 120 字）→ 首组
  • 导入 / 导出当前 / 导出全部 / 恢复当前 / 恢复全部 →「导入、导出与恢复」组；禁用条件照源码：导出当前需已保存，导出全部需有预设，恢复当前仅内置
  • 保存预设 / 另存为 / 删除预设 / 清理疑似异常空块（≥3 个连续「未命名 / system / 空内容」块才出现）→「保存」组；删除仅自定义可用；重名弹「预设名称重复」
  • 消息块卡片（#序号、名称、角色下拉、内容、上移 / 下移 / 删除）→ 每块一张分组卡：标题行（序号 + 名称）、角色分段控件 system / user / assistant、内容 textarea、操作行；首块禁上移、末块禁下移
  • 「添加消息块」→ 列表下方操作行，默认「新消息块 / system / 空内容」；无消息块时显示「当前预设没有消息块。」
  • 占位符说明 → 底部分组，14 项照 placeholders.js
  • 读取中 / 读取失败 → 顶部状态行（工具栏可模拟失败）；读取或处理中控件全部禁用
新增 / 改动
  • 删除消息块：新增确认（源码直接删除）
  • 恢复当前：新增确认（源码直接覆盖）
  • 「未保存」角标：新增，新建预设或草稿与已保存内容不同时显示；有未保存修改时切换 / 新建预设，新增确认「放弃未保存的修改？」（源码静默丢弃草稿）
  • 导出在原型里只弹提示，不下载文件
  • 源码没有启用开关、独立的复制 / 重命名（由「另存为」与改名后「保存预设」承担），本页也没有媒体区块，原型均未添加
