原功能 → 新位置（以 modules/qq-v2/ui/app.js 3057–3267、2018–2100 为准）：
1. 标题「聊天设置」/「群聊设置」、返回 → 公共骨架标题栏「‹ 聊天」。
2. 群资料（头像、群名、「N名成员」/「已退出 · N名成员」）→ 顶部资料卡；群头像只展示。
3. 成员列表 → 资料卡内 4 列网格：自己（名字「我」、不可点、群主 / 管理员角标）、其他成员（可点进入群成员资料，空名「未命名」）、「添加成员」加号格（仅群正常、未退出、我是群主或管理员）。
4. 群名称、备注、聊天背景、世界书各项 → 「资料」「世界书」两组；change 即保存，无保存按钮；深度校验失败在下方状态行提示「保存失败」。
5. 解散 / 退出群聊 → 表单外最后一组红字整行，按 groupLifecycleAction：群主「解散群聊」，管理员 / 成员「退出群聊」，已退出或已解散不显示。
6. 群成员资料 → 背景 + 大头像 + 名字 + 角色；仅 groupMemberManagementActions 非空时显示「编辑资料」。
7. 群成员编辑 → 身份区 + 分组整行操作，权限矩阵与 groupMemberManagementActions 一致。
