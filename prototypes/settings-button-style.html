原功能 → 新位置（源码 pages/button-style.js + appearance-builders.js）：
1. 悬浮入口 · 「显示悬浮按钮」复选框 → 卡片内开关；提示「悬浮入口已显示 / 悬浮入口已隐藏」。
2. 悬浮入口 · 标题右侧「重置位置」 → 同卡片整行操作；提示「悬浮按钮位置已重置」。
3. 「隐藏按钮不影响已打开的手机。」 → 悬浮入口卡片下灰字。
4. 按钮大小 · 滑块 + 数字框 → 只保留滑块，右侧显示数值；拖动时预览实时变化。
5. 「32–72 px，默认 40。」 → 按钮大小卡片下灰字。
6. 按钮形状 · 长方形 / 圆形单选 → 分段控件；提示「按钮已切换为圆形（文字已隐藏）」/「按钮已切换为长方形」。
7. 按钮封面 · 预览框 → 页首「预览」卡片，随大小、形状、封面同步。
8. 上传封面 → 整行操作，打开裁剪弹窗「裁剪悬浮按钮图片」；圆形对应 toggle-cover-circle（1:1，覆盖 0.8），长方形对应 toggle-cover-rounded（2.6:1，覆盖 0.88）；确认后预览换成封面，提示「按钮封面已更新」，清除封面解除禁用。
9. 清除封面（无封面时禁用） → 红字整行；提示「按钮封面已清除」，清除后重新禁用。
10. 「按按钮形状裁剪。」 → 按钮封面卡片下灰字。
新增 / 改动：
· 新增确认：清除封面先弹 YZ.confirm，原代码点了直接清除。
· 大小提示时机：原代码只在数字框 change 时提示「按钮大小已调整为 Npx」；数字框去掉后，改为松开滑块时提示。
· 新增文案：形状卡片下「圆形按钮不显示文字。」（原代码只在切换提示里说明）。
· 预览从封面区块提到页首，三项设置都会影响它。
失败分支（原代码 showToast 错误样式，原型统一用 YZ.toast）：
这只是视觉原型，所有数据都是示例，不连接真实小手机。
