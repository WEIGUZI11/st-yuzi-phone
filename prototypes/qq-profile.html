编辑资料

原功能 → 新位置

  • renderProfileSurface（app.js 1940–1982）→ 资料页：背景层（无背景显示默认渐变）、大头像叠头像框、名称（空显示「未命名」）、状态文字（非空才显示）、「性别 | 生日」摘要与签名行（空不显示）。详情行与源码一致只是装饰，点击无操作。
  • renderProfile（1984–2015）联系人底部操作栏：好友「删除好友 / 编辑资料 / 发消息」；已不是好友「添加好友 / 编辑资料 / 查看消息」，状态文字「已不是好友」。
  • 当前用户资料（2108 处调用 renderProfileSurface）：只有「编辑资料」主按钮；名称取用户名，默认「我」。返回按钮 aria-label 按需求写「当前用户资料」（源码 makeProfileTop 为「返回」）。
  • renderProfileEditorSurface（2220–2290）→ 编辑页：头像、头像框、气泡、消息字色、名字（我的只读）、签名、性别、生日、资料背景，顺序不变；maxLength 沿用 PROFILE_FIELD_META（120 / 1000 / 120 / 120）。
  • 保存：每个字段 change 单独保存，无保存按钮，成功无提示；失败在列表底部状态行显示「保存失败」（源码 3032 / 3050）。

新增 / 改动

  • 分组标题「形象」（1–4）「资料」（5–8）「背景」（9）为新增。
  • 上传 / 删除 / 选择图标按钮 → 整行点击 + 操作菜单，右侧显示缩略图或素材名。
  • 头像「从本地上传」后新增 1:1 裁剪、资料背景新增 3:4 裁剪（源码无裁剪；建议保留，与外观页换图流程一致）。
  • 「删除头像」新增二次确认；「删除资料背景」保持源码的直接删除。
  • 头像框 / 气泡：网格选图面板「选择头像框」「选择气泡」，无「无」选项；点选素材即保存并收起，右上「完成」/ 遮罩 / Esc 等同取消；有值时点行先出操作菜单「选择头像框 / 清除头像框」（气泡同理）。
  • 消息字色下拉框 → 分段控件「白字 / 黑字」，默认我的白字、联系人黑字。
  • 删除好友：源码（4276 附近）为带插图的确认界面，这里改为确认框，文案不变。
  • 删除好友成功后源码会切回联系人标签；原型停留在资料页并切到「已不是好友」，便于预览。

原型模拟

  • 头像、资料背景、素材均为色块；裁剪确认后轮换一张示例图。

  • 「图片资料为空」：选图面板显示「图片资料中还没有可用素材」。
