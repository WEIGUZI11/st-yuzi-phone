原功能 → 新位置

  • assistant.js 姓名 / 头像卡 → 「人物」组：姓名行内输入（change 时保存）、头像行。
  • 聊天背景 / 头像框 / 气泡 / 消息字色卡 → 「形象」组；头像框、气泡的「选择 / 清除」按钮 → 行点击后的选图面板与操作菜单。
  • 人物人设卡 → 「人设」组；操作卡（保存人设 / 恢复默认人设）→ 下方操作组；状态行保留在页底，role=status。
  • 选择人物弹窗（自建人物行 ×、底部「取消 / 新建人物」）→ formSheet「选择陪聊人物」：行内「删除」，列表下方「新建人物」整行，右上角按钮为「取消」。
  • 消息页 + 菜单、创建群聊、添加联系人、联系人导入 / 导出、三种删除会话确认 → 「新建入口与弹窗」视图。

新增 / 改动

  • 「人物」「形象」「人设」三个分组标题为新增。
  • 更换头像后接 1:1 裁剪；源码直接上传（上限 8MB），没有裁剪。
  • 人设有修改时显示「未保存」，有未保存修改时返回会确认是否放弃；源码没有这两项。
  • 头像框 / 气泡有值时先弹「从图片资料选择 / 清除」菜单，代替源码的并排按钮。
  • 删除会话确认：源码 dismissible:false，原型里点遮罩也能关闭。

原型模拟

  • 「人物：内置 / 自建」：切换示例人物；「恢复默认人设」只对内置人物显示。
  • 「模拟素材为空」：选图面板显示「图片资料中还没有可用素材」。
  • 「模拟好友不足」：创建群聊只剩 1 名可用好友，提示并阻止提交。
  • 「模拟创建失败」：添加联系人显示失败状态；导入联系人提示「文件错误」。
  • 头像、背景、素材均为色块示例；所有保存只改页面状态，不落盘。
