新增 / 改动的交互

  • select 改为行 + 底部选择面板，当前值显示在行右侧；未改值不提交（同原 change 事件）。
  • 去掉 hero 卡片；eyebrow 与标题重复，描述移入脚注。
  • 提交中只禁用触发元素，期间其他操作被忽略（对应源码 busy 锁），模拟耗时 400ms。
  • 导入用「选择预设文件（模拟）」面板代替系统文件框，含新预设 / 含 QQ 素材 / 同 ID / 无效文件四例。
  • 加载中 / 错误态与源码一致：分组仍渲染为空，此时提交类操作模拟服务失败，toast「操作失败」，导入 toast「导入失败：文件无效」。
  • 示例数据下无法自然触发的提示「页面美化暂不可用」「弹窗美化暂不可用」「所选美化预设无效」，在页底「原型演示」组用三条模拟行演示。
  • 源码 handleAction 还接受 activate / clear / clear-all（toast「已设为当前美化」「该表已恢复默认展示」），builder 不渲染这些按钮；原型在「原型演示」组提供 activate / clear 入口，clear-all 与「全部恢复页面默认」同路径。
  • 返回按钮仅 toast 提示，原型不跳转。
