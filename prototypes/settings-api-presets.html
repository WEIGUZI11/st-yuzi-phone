原功能 → 新位置

  • 选择预设下拉框（只读项禁用，标「（只读）」）→ 首行 + YZ.sheet，只读项置灰；首项「请选择 API 预设」= 新建草稿。
  • 「新建 API 预设」按钮 → 同组操作行。
  • 名称 / API 地址 / 手写模型 → 行内输入，maxlength 120 / 2048 / 256 照搬。
  • API 密钥（password，不回显）→ 行内密码输入；「（留空保持已有密钥）」移到占位符与分组说明。源码无显示切换，未新增。
  • 「加载模型」→ 操作行；加载中 / 已加载 N 个 / 未识别 / 错误 → 编辑组下方状态行；模型列表下拉 → 有模型时出现的行 + YZ.sheet，选中回填手写模型。
  • 温度（0–2，step 0.01）→ 滑块，两位小数；最大输出（min 1，step 1）→ 步进器 + 点数字精确输入。
  • 「保存预设」「删除预设」→ 操作行；删除沿用源码确认框文案，非新增确认。
  • 读取 / 忙碌时禁用选择与新建；只读或忙碌禁用编辑区；删除仅已保存且可编辑时可用。

新增 / 改动

  • 最大输出精确输入弹层与「请输入不小于 1 的整数」提示、选择弹层说明「只读预设不可选择。」为新增。
  • 源码无复制、独立重命名（改名走名称字段）、测试连接，原型未添加。
  • 模拟规则：地址为空 → 加载模型失败；地址含 /empty → 空列表；名称为空 → 保存失败。真实错误文案来自后端。
